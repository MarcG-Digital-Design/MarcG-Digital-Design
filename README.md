### 💻 Projects

*Below is a selection of my key projects, demonstrating the full design cycle from RTL development to FPGA/SoC integration and real-time hardware validation.*

* **[VGA Video Controller -- DE-10 LITE QUARTUS](https://github.com/MarcG-Digital-Design/fpga-vga-controller)** ![Status](https://img.shields.io/badge/status-ready-brightgreen) -  Custom FPGA VGA controller displaying a static image stored in internal block RAM, featuring automated RTL verification with GHDL, assertion-based VHDL testbenches, and a Makefile-driven simulation flow.

* **[FPGA Digital Stopwatch -- DE-10 LITE MAX10 QUARTUS](https://github.com/MarcG-Digital-Design/fpga-stopwatch)** ![Status](https://img.shields.io/badge/status-ready-brightgreen) - A feature-rich digital stopwatch featuring Play/Pause/Reset functionality, implemented with a **Double Dabble algorithm** for efficient BCD conversion and multiplexed 7-segment display control.

* **[Real-time FPGA Signal Processing -- ZYBO ZYNQ-7000 VIVADO](https://github.com/MarcG-Digital-Design/fpga-signal-processing)** ![Status](https://img.shields.io/badge/status-in_progress-yellow) - Development of a low-pass filter implemented on FPGA.
  * **Full Design Cycle:** Theoretical analysis, coefficient calculation, and MATLAB simulation.
  * **Implementation:** RTL design, SPI interface development for high-speed ADC/DAC communication.
  * **Validation:** Real-time signal processing and performance verification.

* **FPGA/SoC Signal Processing -- ZYBO ZYNQ-7000 VIVADO** ![Status](https://img.shields.io/badge/status-in_progress-orange) - Hardware/software co-design version of the existing FPGA signal-processing project.
  * **Processor:** Handles data acquisition and output transfer.
  * **FPGA:** Performs the FIR filtering in dedicated RTL hardware.
  * **Analysis:** Comparison of latency, throughput, resource usage, and power consumption.
     
* **Multi-Clock FPGA Streaming System -- DE-10 LITE MAX10 QUARTUS** ![Status](https://img.shields.io/badge/status-in_progress-orange) - Final-year project developed from **November to January**, focused on robust multi-clock FPGA design, verification, and timing analysis.
  * **RTL Design:** Multi-clock streaming architecture with FIFO buffering and pipelined processing.
  * **Verification:** Self-checking VHDL testbenches and Python/cocotb automated tests.
  * **Timing & CDC:** Clock Domain Crossing, asynchronous FIFO, SDC constraints, WNS/TNS analysis, and timing closure.
  * **Hardware Validation:** Resource analysis and on-board debugging with Intel SignalTap.
